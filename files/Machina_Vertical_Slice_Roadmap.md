# Machina — Vertical Slice Roadmap

### **Slice 1 — Core Proof of Concept**

**Predict → Explain → Decide → Display**

Prove the fundamental Machina loop works.

* Synthetic sensor input
* Python Random Forest prediction
* Failure probability
* Health score
* SHAP explanation
* Java decision engine
* React dashboard
* Temporary JSON bridge / mock frontend data

**Deliverable:** A demonstrable Machina prototype.

**Current status:** ✅ Complete

---

### **Slice 2 — Predict + Explain Integration**

**React → Gateway → ML**

Remove the prototype shortcuts and connect the prediction services.

* Express gateway running
* `/health` check
* `/api/predict` route
* `/api/explain` route
* Gateway → Python ML communication
* React → Gateway communication
* Real ML prediction displayed in React
* Real SHAP values displayed in React
* Loading/error handling in React

**Deliverable:** A connected multi-service prediction pipeline.

**Current status:** ✅ Complete

---

### **Slice 3 — Java Decision Engine Integration**

**Prediction → Risk Assessment → Maintenance Decision**

Integrate the existing Java Decision Engine so that the maintenance decision is generated by the actual decision logic rather than being hardcoded in React.

* Connect Gateway → Java Decision Engine
* Replace hardcoded React decision with real output
* (Spring Boot deferred until required)

**Deliverable:** A robust Java decision service that converts model output into deterministic maintenance actions.

**Current status:** ⏳ Next

---
